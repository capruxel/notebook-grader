# Notebook grading

This context covers reviewing saved weekly homework notebooks against a course roster and recording student grades.

## Language

**作業說明 (reference notebook)**:
A notebook supplied as the week's comparison reference, not a student's submission.

**學生作業 (submission)**:
A notebook under a homework week that may belong to a roster student; its contents are reviewed without executing it.

**候選線索 (candidate hint)**:
A name or roster ID suggesting which student a file might belong to, without necessarily establishing an assignment.

**自動指派 (automatic assignment)**:
A student–notebook association made when the available ID evidence identifies a single roster student without conflict. A candidate hint alone does not establish an assignment.

**待人工確認 (manual review)**:
A student or file without a single safely reviewable student–notebook pairing, including contradictory IDs or multiple notebooks for one student. The files remain available for inspection.
